## QR CODE GENERATOR
A responsive QR Code Generator built with HTML, CSS, and vanilla JavaScript.
Instantly converts text or URLs into scannable QR codes, with smart sizing across devices.

Simple. Fast. Practical.
👉 Live Demo: https://blessingndeks.github.io/qr-code-gen/

## Features
Generate QR codes from text or links
Responsive QR sizing (mobile → desktop)
Real-time updates
Clean UI, zero frameworks

## Tech Stack
HTML
CSS
JavaScript
QR Code API / Library
